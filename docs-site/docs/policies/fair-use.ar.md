# سياسة الاستخدام العادل

CHERT IoT منصة تعلّم مجانية مشتركة. باستخدامها فأنت توافق على:

- إرسال بيانات من أجهزة تملكها أو مخوّل باستخدامها وبمعدلات معقولة (راجع [الحدود](../guides/limits.md)).
- عدم محاولة الوصول إلى مستأجري الآخرين أو أجهزتهم أو بياناتهم، وعدم فحص المنصة أو التشويش على الآخرين.
- عدم استخدام المنصة لأغراض غير قانونية أو للتحكم الحرج بالسلامة أو لأعباء إنتاج تجارية.
- إبقاء رموز وصولك سرّية وتبديل أي رمز انكشف.

الحسابات المخالفة قد تُعلّق. إن رأيت خللًا أو ثغرة فأخبرنا بدل استغلالها.
