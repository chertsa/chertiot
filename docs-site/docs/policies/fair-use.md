# Fair-use policy

CHERT IoT is a shared, free learning platform. Using it means you agree to:

- Send data from devices you own or are authorised to use, at sensible rates (see [Limits](../guides/limits.md)).
- Not attempt to access other users' tenants, devices or data, probe the platform, or interfere with other users.
- Not use the platform for anything unlawful, for safety-critical control, or for commercial production workloads.
- Keep your access tokens private; rotate a token you have exposed.

Accounts that break these rules can be suspended. If something looks broken or unsafe, tell us instead of exploiting it.
