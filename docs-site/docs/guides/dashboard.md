# Your dashboard

**My dashboard** in the portal opens ThingsBoard with the same sign-in — no second password. You are the **administrator of your own tenant**: you can add widgets, create more dashboards, build rule chains and alarms, and nothing you do is visible to other students.

- The starter dashboard shows every device you own, a temperature and a humidity chart, and a latest-telemetry table.
- To chart another key, edit the dashboard → widget → **Data** → add a key. Any key you published is offered.
- Made a mess? **Reset starter dashboard** in the portal restores the original layout. Your devices and data stay.
- Want an email when a value crosses a threshold? ThingsBoard **Rule chains** → *Root Rule Chain* → add a *filter* node and an *alarm* node. A guided "Alerts" feature in the portal is planned.
