# لوحتك

**لوحتي** في البوابة تفتح ThingsBoard بنفس تسجيل الدخول — دون كلمة مرور ثانية. أنت **مدير مستأجرك الخاص**: أضف عناصر، أنشئ لوحات أخرى، ابنِ سلاسل قواعد وتنبيهات، ولا شيء مما تفعله يظهر لغيرك.

- اللوحة الأساسية تعرض كل أجهزتك، ورسمي حرارة ورطوبة، وجدول آخر القياسات.
- لرسم مفتاح آخر: حرّر اللوحة → العنصر → **Data** → أضف المفتاح.
- أفسدت الترتيب؟ **إعادة ضبط لوحة التحكم الأساسية** في البوابة تعيد التخطيط الأصلي؛ أجهزتك وبياناتك تبقى.
- بريد عند تجاوز عتبة؟ سلاسل القواعد في ThingsBoard تدعم ذلك؛ ميزة "تنبيهات" مبسّطة في البوابة قادمة.
