# ‏MQTT والمواضيع ورمزك

| الإعداد | القيمة |
|---|---|
| الوسيط | `chertiot.com` |
| المنفذ | `8883` (TLS). المنفذ `1883` **غير** متاح علنًا |
| اسم المستخدم | **رمز وصول** جهازك |
| كلمة المرور | فارغة |
| معرّف العميل | أي قيمة فريدة؛ الكود الجاهز يستخدم اسم الجهاز |
| موضوع القياسات | `v1/devices/me/telemetry` |
| موضوع الخصائص | `v1/devices/me/attributes` |

**الحمولة** JSON: إما `{"key": value, ...}` (يُختم وقت الوصول) أو `{"ts": 1700000000000, "values": {...}}` بوقتك الخاص.

**الرموز لكل جهاز.** الرمز يكتب في جهازه فقط — لا يقرأ شيئًا ولا يصل إلى جهاز آخر أو بيانات طالب آخر. فقدت رمزًا أو نشرته؟ افتح صفحة الجهاز واضغط **إصدار رمز جديد**؛ يتوقف القديم فورًا.

**TLS:** الشهادة عامة (Let's Encrypt). معظم بيئات Arduino وMicroPython تقبلها افتراضيًا.
