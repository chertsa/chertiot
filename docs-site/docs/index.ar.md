# مختبرك الخاص لإنترنت الأشياء، جاهز خلال عشر دقائق

يمنحك CHERT IoT مستأجر ThingsBoard خاصًا بك: أجهزة ولوحات تحكم مباشرة وسلاسل قواعد وتنبيهات لك وحدك. لا شيء تثبّته على خادم، ولا شيء تدفعه.

## طريق الدقائق العشر

1. **أنشئ حسابًا** في [chertiot.com](https://chertiot.com/signup) وافتح رسالة التفعيل.
2. **سجّل الدخول** — تسجيل دخول واحد يفتح البوابة *و*لوحة التحكم.
3. افتح **أجهزتي** → جهازك الأول جاهز. انسخ رمز الوصول الخاص به.
4. اختر لوحتك أدناه، والصق الرمز في الكود الجاهز، وشغّله.
5. شاهد القراءات تصل إلى **لوحتي**.
