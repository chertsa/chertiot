# ESP32 مع بيئة Arduino

**تحتاج إلى:** أي لوحة ESP32، وكابل USB، وبيئة Arduino IDE 2.x مع حزمة لوحات *esp32*، ومكتبة **PubSubClient** (مدير المكتبات → ابحث عن "PubSubClient").

1. في البوابة افتح **أجهزتي → جهازك** ونزّل `chertiot_starter.ino`. رمزك وعنوان الوسيط بداخله.
2. عيّن `WIFI_SSID` و`WIFI_PASSWORD` أعلى الملف.
3. اختر اللوحة والمنفذ واضغط **Upload**، ثم افتح Serial Monitor على 115200. سترى `WiFi ok` ثم `MQTT connecting... ok` وسطر JSON كل 10 ثوانٍ.
4. افتح **لوحتي**: تتحرك رسوم الحرارة والرطوبة خلال ثوانٍ.

## إرسال بيانات مستشعر حقيقي
الكود الجاهز يرسل قيمًا عشوائية. استبدل سطري `temperature` و`humidity` بقراءة من مستشعرك (DHT22، BME280، …) وأبقِ مفاتيح JSON كما هي — الرسوم مربوطة بها.

## استكشاف الأخطاء
| العرض | السبب | الحل |
|---|---|---|
| `MQTT connecting... failed rc=5` | رمز خاطئ | انسخ الرمز مجددًا من صفحة الجهاز؛ هو **اسم مستخدم** MQTT وكلمة المرور تبقى فارغة |
| `rc=-2` | لا مسار إلى الوسيط | تحقق من الشبكة؛ الوسيط `chertiot.com` منفذ `8883` (TLS) |
| اتصال دون بيانات | موضوع خاطئ | يجب أن يكون بالضبط `v1/devices/me/telemetry` |
| توقف بعد دفعة | حد المعدل (10 رسائل/ثانية للجهاز) | أرسل قراءة كل بضع ثوانٍ؛ راجع [الحدود](../guides/limits.md) |
