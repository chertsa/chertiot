# Your own IoT lab, live in ten minutes

CHERT IoT gives you a private ThingsBoard tenant: devices, live dashboards, rule chains and alarms that are yours alone. Nothing to install on a server, nothing to pay for.

## The ten-minute path

1. **Create an account** at [chertiot.com](https://chertiot.com/signup) and open the verification email.
2. **Sign in** — the same sign-in opens your portal *and* your dashboard.
3. Open **My devices** → your first device is already there. Copy its access token.
4. Pick your board below, paste the token into the starter code, run it.
5. Watch the readings arrive on **My dashboard**.
